## 확인 방법과 한계

- 시안: 로컬 서버로 39개 화면을 열어 화면별 문구·입력 요소를 뽑았다.
- React: 화면 코드(`src/pages/**`)를 읽어 대조했다. Supabase 연결이 없어 **실제로 띄워 본 건 시작·로그인 화면뿐**이다. 나머지 화면은 코드 기준이라 여백·색 같은 미세한 시각 차이는 빠져 있을 수 있다 → Supabase 키를 넣으면 스크린샷으로 한 번 더 확인.

분류: 🔧 FE만 고치면 됨 · 🗄 BE(DB 컬럼·API)가 있어야 함 · ✋ 이식하면서 일부러 바꾼 것 (유지할지 확인) · ❓ 팀 결정 필요

## 3. 정리

**FE만으로 바로 맞출 수 있는 것 (🔧)**
1. 폰트 경로 (A) — 한 줄 수정, 영향이 가장 큼

**팀 결정이 필요한 것 (❓)**
- 사장님에게 단체 이름을 보여줄지 (시안·문구는 익명, 실제 데이터는 실명) — 개인정보 관련이라 우선
- S-11 영수증 입력을 "품목 금액"으로 할지 "단가"로 할지
- S-12 가게 분석 차트를 소비 금액으로 할지 예약 수로 할지
- 큰 글씨 모드를 앱 안 설정으로 넣을지 (D-09)
- 가게 등록 때 대표 사진을 필수로 받을지 (D-05)

**BE 없이는 못 맞추는 것 (🗄)**: 단체 소속·활동 지역·인원 규모, 가게 업종·상세주소·영업시간·사업자번호, 빈자리 최소 인원·1인 금액·안내·날짜별 조건, 사전 주문 알레르기 메모, 미응답자 명단, 미충족 수요 개별 목록, 추천 메뉴, 소셜 로그인. 발표 범위에서는 **빼는 것으로 두고** 시안을 기준 문서로 남기는 걸 제안.
