# PR20·21 및 기능 오류 통합 검증 — 2026-10-08

PR20(abcdf9d), PR21(614570f), 기존 기능 오류 수정(90c81b9)을 `codex/integrate-pr20-21-audit`에 통합했다. main 병합과 운영 배포, 운영 DB 변경은 수행하지 않았다.

## 반영 내용

- 소셜 로그인·역할 선택, 비밀번호 재설정, 약관, 가입 사진, 주간 분석 기능 유지.
- 가게·단체 추가 입력 칸, 업종 필터, 알레르기 메모, 날짜별 최소 인원·금액·안내 유지.
- 기존 12개 오류 그룹(영수증 저장·미저장 확정·실패 시 입력 유지·빈 품목, 결제 검증, 빈자리 일괄 등록·재시도·과거 날짜, 요청 재시도 시각, 숫자 검증, 참석 마감, 결제 수단 표시) 유지.
- 날짜별 조건을 한 번의 원자적 등록에 포함하고, 0원과 빈 입력을 구분한다. 부분 실패 시 슬롯과 재시도 기록 전체를 롤백한다.
- 참석 응답 시 예약 인원을 유지하고 마감 때만 반영한다. 슬롯 최소 인원 미달이면 마감과 알림을 보류한다. 최소 인원 없는 조사에서 참석 0명이면 기존 예약 인원을 유지한다.
- 마감 후 응답·삭제 차단 및 잠금 대기 후 최신 마감 상태 재검사.
- 가입·수정 인원 상한 200 및 정수 검증 보완. 시연 seed의 SQL 종료 구문 오류와 마감 전 인원 변경도 수정했다.
- 기존 디자인 토큰과 스타일 유지.

## 충돌 및 DB 적용 순서

README, check_migrations.sql, Slots.tsx, SlotBook.tsx의 충돌을 해결했다. 친구의 010·011을 유지하고 미적용 상태의 기존 기능 감사 SQL을 012로 옮겼다.

001~009가 있는 DB는 **010_social_login.sql → 011_proto_fields.sql → 012_functional_audit.sql** 순서로 적용한 뒤 FE를 배포해야 한다. 이미 별도 `010_functional_audit.sql`을 적용한 환경은 이 문서의 전제가 아니므로 재적용하지 말고 적용 이력을 확인해야 한다.
