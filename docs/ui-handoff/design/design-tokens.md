## 모션과 입력

선택 유지 220ms, 영역 펼침 360ms, 접힘 260ms, 다음 입력까지의 안내 스크롤 520ms입니다. OS의 모션 줄이기 설정에서는 모션을 줄이거나 제거합니다. 날짜와 시간은 같은 둥근 선택 시트·중앙 선택 줄·확인 버튼을 사용합니다. 휠은 마우스, 터치, 방향키를 지원하고 취소하면 기존 값을 유지합니다.

기본·선택·비활성·포커스·오류와 빈 상태·로딩·권한 없음은 공통 표현을 사용합니다. 거절·취소 행동에는 별도 확인을 두고, 읽기용 정책 링크는 굵기와 밑줄로 강조합니다. 파란색과 초록색은 역할 차이를 보여주며 동작 성공을 색만으로 전달하지 않습니다.

## 이전 버전

`tokens-v0.2.css`는 이전 비교 시안 B–E의 값을 고정해 보존합니다. `tokens.css`는 이 파일의 기본 변수 위에 승인 A2 값을 덮어씁니다. 이전 명세와 미리보기는 각각 `design-tokens-v0.2.md`, `tokens-preview-v0.2.html`에 보존했습니다. 새 작업은 현재 `tokens.css`와 승인 명세를 기준으로 합니다.

## 4.2 글자·선택 개선

기존 로컬 Pretendard Variable을 유지하고 본문 500, 입력·선택 650, 제목 750의 굵기를 사용합니다. 본문 자간은 -0.018em, 제목은 -0.035em으로 정돈했습니다. 토스의 전용 글꼴을 복제하거나 외부 글꼴을 추가한 것은 아닙니다.

단체 유형·가게 업종·영수증 메뉴 연결은 브라우저 기본 선택 메뉴 대신 앱 안의 바텀시트를 사용합니다. 현재 값, 선택 체크, 필요한 경우 유형 설명을 표시하고 ‘선택 적용하기’에서 값이 반영됩니다. 닫기·Escape는 기존 값을 유지합니다. 방향키와 Home/End로 항목을 선택할 수 있습니다. 리뷰 도구의 화면 상태 메뉴는 제품 UI 밖에 남깁니다.

## 4.3 주요 행동·상태 강조

주요 행동 버튼은 999px 캡슐 반경, 역할 색의 은은한 그라데이션, 위쪽 하이라이트와 아래 3px 깊이·부드러운 그림자를 사용합니다. hover와 누름 상태에서 그림자가 바뀌고 모션 줄이기에서는 위치 이동을 제거합니다. 비활성 버튼은 그림자가 없는 중립색으로 표시합니다.

상태 배지는 둥근 캡슐에 2px 테두리와 가벼운 그림자를 둡니다. 결제 대기는 따뜻한 앰버 배경·테두리와 굵기 750을 사용합니다. 확정·거절·취소도 상태별 테두리를 사용합니다. 상태 배지는 안내 요소로 유지합니다. `components-emphasis.css`를 전체 화면과 승인 A2 화면에서 함께 사용합니다.

## 4.4 아이콘·현재 위치 표시

기존 SVG 그림 아이콘 전체에 공통 밝기 그라데이션, 앞뒤 레이어 그림자와 둥근 받침을 적용했습니다. `icon-depth.js`는 새로 생성되는 그림에도 같은 규칙을 적용합니다. 기능 아이콘과 하단 메뉴에도 가벼운 받침과 선명한 선을 사용합니다.

하단 메뉴의 현재 위치는 역할과 관계없이 파란색 면·흰색 아이콘·굵은 파란 글자로 표시합니다. 사장님의 주요 행동 버튼은 기존 초록색을 유지합니다. 미충족 수요는 운영자에게는 수요, 사장님에게는 분석 메뉴 위치로 표시합니다.

공유 ZIP은 사용자가 이 버전을 승인했을 때만 새로 생성합니다. 현재는 로컬 검토용 수정본이며 기존 4.3 ZIP은 이전 결과입니다.

목록 행의 여백: 홈의 이동 목록(`.link-list > .list-link`)과 메뉴 행(`.menu-row`)은 위·아래 16px로 맞춥니다. 한 목록 안에서는 행마다 섹션 여백이나 별도 gap을 추가하지 않으며, 참석자·순위 목록은 기존의 대칭 14px 여백을 유지합니다.


## 4.5 떠 있는 선택 메뉴

`--radius-choice-menu:22px`, `--choice-row-height:56px`, `--shadow-choice-menu`를 공통 선택 메뉴에 적용합니다. 메뉴 항목은 18px·굵기 650, 현재 선택은 750이며 얇은 구분선과 체크로 구분합니다. 입력칸 가까이에 위치하고, 한 번 선택하면 바로 반영합니다. 바깥 영역·Esc는 취소합니다. 일반 입력칸은 16px 전체 모서리와 최소 60px 높이의 면을 사용합니다.


## 4.6 통계·상태 정리

`--status-border-width:0px`와 그림자 없음으로 상태 배지를 평평한 색 면으로 표시합니다. 통계는 같은 폭의 카드, 제목 위 정렬, 숫자 아래 정렬을 사용합니다. 긴 금액 단위가 있는 세 칸 통계는 모든 숫자의 표시 크기를 함께 조절합니다. 제목 줄 수 때문에 숫자의 높이가 달라지지 않습니다.


## 4.7 기능 아이콘·버튼 강도

상단 기능 아이콘은 배경·테두리·그림자 없음과 최소 48px 터치 영역을 사용합니다. `--shadow-action-glow`는 파란 역할·초록 역할·위험 확인 모두 `0 2px 6px`, 불투명도 8%로 낮췄습니다. 주요 버튼은 단색과 테두리 없음으로 표시하고 hover·누름에서 색만 변경합니다. 누름 상태의 그림자는 없습니다.


## 4.8 역할과 캘린더 공통 규칙

하단 탐색은 받침·그림자가 없는 25px 선 아이콘과 텍스트입니다. 현재 탭은 단체 #485AC8 / 사장님 #226347로 구분합니다. 중앙 액션은 48px 원형과 1.5px 역할 색 테두리, 옅은 역할 색 면으로 별도 깊이의 기능을 나타냅니다. 기능 아이콘·상태 배지·주요 버튼은 기존 4.7의 표현을 유지합니다.

로그인 브랜드 토큰은 카카오 #FEE500, 네이버 #03A94D입니다. 세 로그인 버튼은 높이 56px·반경 12px·간격 12px, 동일한 글자 크기와 굵기를 사용합니다. 알림은 안 읽음 .83 / 읽음 1의 불투명도와 상태 점을 함께 사용합니다.

캘린더는 7열, 날짜 버튼 높이 44px, 선택 시 옅은 역할 색과 1px 테두리를 사용합니다. 일반 컨트롤은 기존 48px 기준을 유지합니다. 카드 반경 20px, 달력 반경 22px, 조건 입력 반경 16px, 제목/입력/보조문구는 공통 타입을 참조합니다. 월 이동 시 해당 월의 일정이 있는 첫 날짜를 선택하고 일정이 없으면 1일로 이동합니다.

새 흐름은 `full-ui/experience.js` / `experience.css`, 공통 탐색은 `components-icons-navigation.css`에서 관리합니다. [4.8 구현·검증](../full-ui/README.md).


## 4.9 인증과 중앙 탐색 강조

인증 화면 로고는 `--size-auth-logo:88px`, 제목은 공통 `--text-title1-size:26px`와 굵기 750입니다. 온보딩과 로그인에서 같은 위치·간격을 사용합니다. 중앙 메뉴는 `--size-navigation-action:72px`, 아이콘 24px와 글자 12px 묶음을 원 안에 가운데 정렬합니다. 메뉴 바 위로 20px 올리고, 역할별 그라데이션과 `0 8px 20px`·불투명도 18%의 부드러운 그림자를 적용합니다. 일반 탭에는 받침이나 입체 효과를 추가하지 않습니다.

단체 중앙 버튼은 #5A74EC→#4155C6, 사장님은 #42966F→#236648입니다. 기존 4.8의 중앙 48px 테두리 원을 대체합니다. 공통 탐색 원본은 `components-icons-navigation.css`이며 중복된 탐색 CSS를 `experience.css`에서 제거했습니다.


## 4.10 캘린더 내용별 색과 참석 정보

역할색과 별도로 `--color-calendar-requests*`는 요청/내 예약의 파랑(#5669E3, 글자 #485AC8, 면 #F3F5FF), `--color-calendar-slots*`는 공개 빈자리의 초록(#267253, 글자 #226347, 면 #F0F7F3)을 정의합니다. `--radius-calendar-panel:26px`의 동일한 면 안에 달력과 날짜별 결과를 함께 배치합니다. 선택 날짜는 각 색의 단색 면·흰 글자로 구분하며, 빠른 등록 버튼은 단체 파랑 / 사장님 초록입니다. 하단 메뉴의 역할 색은 캘린더 탭과 독립적으로 유지합니다.

참석 정보는 `--color-attendance-surface:#F6F7FB`, 진행 바 바탕은 `--color-attendance-track:#E2E6F3`입니다. 응답한 참석 인원과 전체 응답 대상, 참석 응답 마감을 우선 표시하고 미정인 결제 기한은 12px 보조문구로 표시합니다. 인증 로고·제목·탐색 규칙은 4.9를 유지합니다.


## 4.10.1 캘린더 전환 영역

`--color-calendar-switch-bg:#F3F4F7`의 단일 영역 안에 두 항목을 배치합니다. 영역 반경 18px·내부 여백 4px, 항목 반경 14px·최소 높이 48px입니다. 선택 면은 흰색, `--shadow-calendar-switch:0 1px 4px rgb(17 24 39 / .06)`과 굵기 650, 비선택은 그림자 없이 굵기 550입니다. 선택 아래쪽 선은 제거하고 요청 파랑·빈자리 초록 글자로 구분합니다.


## 4.10.3 모임 관리의 보조 행동

참석 현황·참석 링크는 `--color-meeting-action-bg:#F0F2FC`, hover #E9EDFC, pressed #E1E6FC와 `--shadow-meeting-action:0 1px 4px rgb(72 90 200 / .06)`을 사용합니다. 반경 14px·테두리 없음·높이 최소 48px입니다. 사전 주문 준비는 투명한 기본 면에 pressed 색으로 즉시 반응하며, 놓으면 140ms로 복귀합니다. 키보드 초점에서는 옅은 브랜드 면과 기존 초점 테두리를 유지합니다. 모션 감소 설정에서는 전환 애니메이션을 제거합니다.


## 4.10.4 테두리 없는 필터와 보조 행동

전체 화면의 `controls.css`를 승인 iframe에도 적용합니다. 필터·보조 행동·응답 선택·유형 선택은 테두리와 강한 그림자 없이 옅은 면으로 구분합니다. 캘린더에서 선택한 필터는 `--color-filter-requests-selected:#E4E9FF`, `--color-filter-slots-selected:#DFEEE5`를 사용하며 선택 글자는 각 캘린더 내용 색과 굵기 750을 사용합니다. 누름은 브랜드색 14%와 흰색을 섞은 면으로 즉시 반응합니다. 기존 키보드 초점 표시, 역할 선택 카드, 모임 관리 행동의 작은 그림자는 유지합니다.


## 4.10.5 전체 버튼의 누름 반응 통일

모임 종류의 옅은 면과 부드러운 선택 느낌을 전체 행동의 기준으로 사용합니다. 모든 활성 버튼은 누르는 즉시 배경색이 바뀌며, 선택형 행동은 손을 떼면 선택 색과 기존 선택 상태를 유지합니다. 글자·상단 아이콘·알림·가게·요청 카드·캘린더·빠른 등록·하단 메뉴·승인 iframe·선택 팝오버에도 적용합니다. 역할 카드는 테두리 없이 파랑·초록 선택 면을 유지하고 가게·요청 버튼 카드의 외곽 테두리도 제거합니다. 주 행동의 브랜드 면, 카카오·네이버 색, 중앙 탐색 강조, 키보드 초점, 비활성 상태는 유지합니다. 공유 ZIP은 생성하지 않았습니다.


## 4.10.8 캘린더 원형·연결 선택

날짜 선택의 테두리를 제거하고 단일 선택은 원형, 같은 주에 이어진 선택 날짜는 가로 캡슐로 연결합니다. 빈자리 일괄 등록의 개별 날짜 선택·해제는 유지하며 비어 있는 날짜는 연결하지 않습니다. 주·달 경계에서는 해당 줄의 끝을 둥글게 마감합니다. 파랑·초록 계열의 옅은 면을 사용하고, 누르는 순간 원형 면이 조금 진해집니다. 숫자는 중앙에 맞추고 일정 점 표시는 유지합니다. 선택 표시 크기는 36px, 작은 화면에서는 30px이며 터치 영역은 기존 44px를 유지합니다. 공유 ZIP은 생성하지 않았습니다.


## 4.10.9 예약 요청의 단계 버튼

모임·일정·조건·메모 단계는 하단 선을 제거하고 반경 14px의 둥근 면으로 구분합니다. 선택한 단계에는 기존 옅은 파란 면과 `--shadow-progress-step:0 2px 6px rgb(72 90 200 / .07)`의 작은 그림자를 넣습니다. 누르는 동안에는 즉시 색이 바뀌고 작은 안쪽 그림자가 표시되며 선택·누름 모두 같은 모서리를 유지합니다. 최소 높이 48px, 기존 단계 이동·선택 점·키보드 초점은 유지합니다. 공유 ZIP은 생성하지 않았습니다.


## 4.10.10 예약 요약과 날짜·시간 입력

예약 상세의 모임 종류 글씨를 14px에서 17px·굵기 650으로 키우고 요약 내부 간격을 16px에서 12px로 줄였습니다. 가게명 없이 모임 종류만 표시되는 경우에는 19px로 강조합니다. 날짜·시간 입력은 예상 인원 숫자 입력과 같은 반경 16px·높이 최소 60px의 옅은 회색 면을 사용하며 하단 선을 제거합니다. 누름·hover 색은 브랜드색 8%로 낮췄습니다. 공유 ZIP은 생성하지 않았습니다.


## 4.11.5 필터·탭의 둥근 사각형 통일 (현재 규칙)

개별 원형 필터 대신 **하나의 긴 둥근 사각형 안에 동일 너비의 선택 항목**을 배치합니다. 예약 상태·업종·참석 명단·미충족 수요·가게 찾기 필터, 진행 중/지난 예약·판매 중/판매 중지·주/월 분석·알림 목록 전환, 캘린더 내용 전환과 예약 요청 단계가 같은 컴포넌트를 사용합니다. 기존 4.10.1, 4.10.4, 4.10.9의 해당 선택 영역 표현을 이 규칙으로 대체합니다. 날짜의 원형·연속 선택과 하단 중앙 예약 버튼은 각각 날짜 선택·주 행동 컴포넌트를 유지합니다.

| 용도 | CSS 토큰 | 값 |
|---|---|---|
| 전체 배경 | `--color-segment-track` | `#F4F6FA` |
| 전체 / 항목 반경 | `--radius-segment-track` / `--radius-segment-item` | 16px / 12px |
| 내부 여백 / 항목 간격 | `--space-segment-padding` / `--space-segment-gap` | 4px / 4px |
| 항목 세로 / 가로 여백 | `--space-segment-item-block` / `--space-segment-item-inline` | 8px / 4px |
| 최소 항목 높이 | `--height-segment-item` | 48px |
| 글자 | `--text-segment-size` | 15px × 공통 글자 배율 |
| 기본 / 선택 굵기 | `--font-weight-segment-idle` / `--font-weight-segment-selected` | 650 / 750 |
| 파랑 선택 배경 / 글자 | `--color-segment-selected-bg` / `--color-segment-selected-text` | `#EEF1FF` / `#485AC8` |
| 초록 선택 배경 / 글자 | 같은 토큰의 사장님·빈자리 컨텍스트 | `#EAF4EE` / `#226347` |
| 선택 그림자 | `--shadow-segment-selected` | `0 1px 4px rgb(17 24 39 / .06)` |
| 비선택 hover 배경 | `--color-segment-hover` | `#FFFFFF` |
| 누름 색 강도 | `--opacity-segment-pressed` | 해당 브랜드색 14% + 흰 면 |
| 놓을 때 전환 | `--duration-segment-release` | 140ms (누름 즉시 / 모션 감소 시 0ms) |

공통 구현은 [segmented-controls.css](segmented-controls.css)입니다. 전체 UI·승인 iframe과 두 현재 토큰 미리보기가 동일 CSS를 불러옵니다. 항목 간 테두리·하단 강조선은 없고 선택한 항목만 옅은 면과 작은 그림자로 구분합니다. 짧은 항목은 한 줄로 표시하며 긴 항목은 작은 화면에서 두 줄 이상으로 자연스럽게 읽을 수 있고 모든 항목 높이는 동일하게 늘어납니다. 버튼은 `aria-pressed`(요청 단계는 `aria-current="step"`)로 선택 상태를 전달하며 키보드 초점 표시와 Enter/Space를 유지합니다. 캘린더 전환의 요청 항목은 파랑, 빈자리 항목은 초록으로 개별 강조합니다.

`--color-calendar-switch-bg`, `--shadow-calendar-switch`, `--radius-progress-step`, `--color-filter-requests-selected`, `--color-filter-slots-selected`는 이전 컴포넌트 호환용 이름으로 남기고 새 규칙 값에 연결했습니다. 새 필터·탭 구현에는 `--*-segment-*`와 공통 CSS를 사용합니다.


## 4.12.1 항목 버튼의 여유 있는 둥근 면

메뉴 행·홈 바로가기·알림·예약 준비·예약 요청 펼치기 제목·다음 단계 버튼은 테두리 없이 같은 둥근 직사각형을 사용합니다. 배경색은 기본 면을 유지하며 hover와 누르는 순간에만 기존 역할 색을 옅게 채웁니다. 눌렀을 때 모서리가 각지거나 내용이 이동하지 않습니다.

| 용도 | 토큰 | 값 |
|---|---|---|
| 모서리 | `--radius-action-row` | 20px |
| 세로/가로 안쪽 여백 | `--space-action-row-block` / `--space-action-row-inline` | 16px / 16px |
| 아이콘·텍스트 간격 | `--space-action-row-gap` | 12px |
| 최소 높이 | `--height-action-row` | 80px |
| 목록 사이 간격 | `--space-action-row-list-gap` | 8px |

공통 구현은 [controls.css](../full-ui/controls.css)이며 전체 UI와 승인 iframe에 적용합니다. 긴 설명과 큰 글씨에서는 높이가 자연스럽게 늘어납니다. 기존 파랑/초록 누름 색 14%, 즉시 반응, 초점 표시와 실제 액션은 유지합니다.
