# 월계더링 콘텐츠 인벤토리

| | |
|---|---|
| 버전 | v0.1 (초안) |
| 작성일 | 2026-10-03 |
| 작성 | FE 이원우 |
| 짝 문서 | [IA](IA.md) — 화면 ID는 IA와 동일 |
| 기준 | BE 마이그레이션 001~007, `wolgyedeoring-backend/docs/API.md` |

화면마다 **무엇을 보여주고(표시) 무엇을 받는지(입력·행동)**, 그리고 그 데이터가 **BE 어디에서 오는지** 정리한다.
BE 담당자는 **[7. BE 요청 목록](#7-be-요청-목록)** 만 먼저 봐도 된다.

> 유저플로우가 바뀌면 화면 단위로 이 문서를 고친다. 항목을 지울 때는 줄을 지우지 말고 ~~취소선~~ 처리한다 (BE가 이미 작업했을 수 있음).

### 표기

| 데이터 상태 | 의미 |
|---|---|
| ✅ | API로 바로 가져올 수 있음 |
| ⚠️ | 가능하지만 가공·조합이 필요하거나 문서와 다름 |
| ❌ | 없음 → BE 요청 필요 |
| ⏸ | TBD 이슈 결정 대기 |

| 유형 | 의미 |
|---|---|
| 표시 | 화면에 보여주는 정보 |
| 입력 | 사용자가 입력하는 값 |
| 행동 | 버튼 등 상태를 바꾸는 동작 (호출하는 API 표기) |

코드값(`event_type` 등)의 한글 라벨은 FE에서 매핑한다 (API.md 코드값 표 기준).
