## 2. 컬러

### 포인트 컬러: 월계수 그린

- 서비스명 '월계'(月溪, 그리고 발음이 같은 월계수 laurel)에서 가져왔다. 지역성과 '함께 모여 축하하는 자리'(월계관)를 연결한다.
- 그린은 성공 톤과 겹치므로, **성공 톤을 브랜드 그린으로 통합**해 전체 색 수를 줄였다. "확정·완료"가 브랜드 색으로 보이는 것은 의도다.
- **2번째 포인트 컬러는 두지 않았다.** 주의(앰버)·위험(레드)은 상태 전용이라 포인트로 쓰지 않는다. 시연에서 강조색이 더 필요하면 v0.2에서 검토.

### 쓰는 규칙

| 규칙 | 예 |
|---|---|
| 브랜드 색 채움 버튼은 **화면당 1개** | 예약 요청 보내기, 결제하기, 수락하기 |
| 나머지 버튼은 회색 테두리 또는 텍스트 버튼 | 취소, 나중에 |
| 상태 배지는 `--tone-*` 쌍(bg + fg)으로만 | 결제 대기 = warning |
| 위험 행동(취소·삭제)은 `--tone-danger-fg` 텍스트 버튼 + 확인 단계 | 예약 취소 |
| 순수 검정·순수 회색 금지, 중립은 `--gray-*` (약간 따뜻한 회색) | |

### 대비 검증 (WCAG 2.1)

텍스트 4.5:1, 입력칸 테두리 등 UI 경계 3:1 기준. 비활성 텍스트는 기준 예외.

| 조합 | 라이트 | 다크 | 결과 |
|---|---|---|---|
| 주 텍스트 / 배경 | 17.78 | 15.85 | ✅ AAA |
| 보조 텍스트 / 배경 | 7.16 | 9.01 | ✅ AAA |
| 메타 텍스트 / 배경 (연한 면 포함) | 4.93 이상 | 5.41 이상 | ✅ AA |
| 브랜드 버튼 글자 / 버튼 | 6.45 | 5.51 | ✅ AA |
| 브랜드 링크 / 배경 | 8.76 | 8.14 | ✅ AAA |
| 상태 배지 글자 / 배지 배경 (5톤) | 4.93 ~ 9.33 | 5.03 ~ 9.16 | ✅ AA |
| 입력칸 테두리 / 배경 | 3.38 | 3.57 | ✅ UI 3:1 |
| 포커스 링 / 배경 | 4.61 | — | ✅ |

## 3. 타이포그래피

- 서체: **Pretendard** (한글·숫자 가독성, 무료, 웹폰트 CDN 제공). 금액은 `font-variant-numeric: tabular-nums` 로 자릿수 정렬.
- 굵기: 400 / 600 / 700 세 가지만.

| 토큰 | 크기 / 행간 | 굵기 | 용도 | 화면당 |
|---|---|---|---|---|
| `display` | 28 / 37 | 700 | 결제 금액, 완료 메시지 | 최대 1개 |
| `title1` | 22 / 30 | 700 | 화면 제목 | 1개 |
| `title2` | 19 / 27 | 600 | 섹션·카드 제목 | |
| `body1` | 17 / 26 | 400, 600 | **기본 본문**, 버튼, 입력값 | |
| `body2` | 15 / 22 | 400 | 보조 설명, 목록의 두 번째 줄 | |
| `caption` | 13 / 18 | 600 | 배지, 입력 도움말 | 핵심 정보 금지 |

**본문을 17px로 잡은 이유**: 일반 앱 기본(15~16px)보다 한 단계 크다. 사장님이 주방·카운터에서 팔 길이 거리로 보는 상황을 가정했다. 학생 사용자에게도 답답하지 않은 상한선.

**정보 위계 예시 (예약 카드)**

```
[결제 대기]                       ← caption · warning 배지
고기굽는집                         ← title2 · 주 텍스트
10/14(화) 19:00 · 32명             ← body1 · 주 텍스트 (핵심 정보)
사전 주문 412,000원 · 1인 12,875원  ← body2 · 보조 텍스트
3시간 전 수락                      ← caption · 메타 텍스트
```

### 큰 글씨 모드

`<html data-font-size="large">` 를 넣으면 모든 글자가 1.125배. 사장님 설정 화면(S-14)에 토글로 제공하는 것을 제안한다. 레이아웃이 깨지지 않도록 **글자 크기에 고정 높이를 주지 않는다** (`min-height` 사용).

## 4. 간격·크기·모서리

| 토큰 | 값 | 용도 |
|---|---|---|
| `--space-1 ~ 14` | 4px 단위 (4, 8, 12, 16, 20, 24, 32, 40, 56) | |
| `--page-gutter` | 16px | 화면 좌우 여백 |
| `--content-max-width` | 480px | PC에서 열어도 모바일 폭 유지 |
| `--touch-target-min` | 48px | 모든 탭 가능한 요소 |
| `--control-height-lg` | 56px | 화면 하단 고정 주요 버튼 |
| `--radius-sm / md / lg / full` | 8 / 12 / 20 / 999 | 입력칸 / 카드·버튼 / 바텀시트 / 배지 |
| `--shadow-raised` | 1종 | 바텀시트·토스트에만. 카드는 선(`--color-border`) |

## 5. 모션

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--duration-instant` | 100ms | 버튼 눌림(`scale 0.98`), 체크 |
| `--duration-fast` | 180ms | 배지·토스트 등장, 색 전환 |
| `--duration-base` | 260ms | 화면 전환, 바텀시트 |
| `--duration-slow` | 400ms | 결제 완료·예약 확정 순간 (드물게) |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 기본 |
| `--ease-decelerate` / `accelerate` | | 들어올 때 / 나갈 때 |

**규칙**
- 움직임은 "무엇이 바뀌었는지" 알려줄 때만 쓴다. 반복 애니메이션, 튀는(bounce) 효과 없음.
- 이동 거리는 짧게 (8~16px 슬라이드 + 투명도). 화면 전체가 날아다니지 않게.
- `prefers-reduced-motion` 이면 지속 시간 0, 눌림 축소 없음 (토큰에서 자동 처리).
- 세련됨은 **"확정" 같은 핵심 순간 1~2곳**에서만 보여준다 (예: 결제 완료 체크 아이콘이 그려지는 400ms 모션).

## 6. 사용법 (FE)

```css
/* main.css */
@import "./tokens.css";

body {
  font-family: var(--font-family);
  font-size: var(--text-body1-size);
  line-height: var(--text-body1-lh);
  color: var(--color-text-primary);
  background: var(--color-bg);
  letter-spacing: var(--letter-spacing-normal);
}
```

- 컴포넌트는 **의미 토큰**(`--color-*`, `--tone-*`)만 쓴다. 원시값(`--laurel-600`, `--gray-500`)을 직접 쓰지 않는다 → 다크 모드·리브랜딩이 한 곳에서 끝난다.
- 프로젝트가 생기면 `tokens.css` 는 `wolgyedeoring-frontend/src/styles/` 로 옮기고 이 문서의 경로를 고친다.
